Volume II · Software's New Customer

The Second Audience

Ten sources, one converging claim: software's primary customer is changing species. Agents are getting accounts, protocols, runtimes, and price cuts built for them — and every product built for human eyes now faces one question: would an agent still need you?

10 sources · 2 diagrams · ~23 min read Distilled from NotebookLM · personal reading log

§1 · OrientationThe week the internet got a second user base

Today's reading looks scattered — a protocol release candidate, a markdown file for signups, a Chinese price cut, a profitability projection, a design tool, a PowerPoint add-in, a creative supercomputer, a government equity grab — until you notice every piece answers the same request from the same new customer. Ramdial names the customer plainly: a second audience of software agents that never sleeps, reads your docs literally, and doesn't care about your brand. The MCP release candidate rebuilds the protocol layer so that audience can scale; auth.md, shipped yesterday, lets it open accounts; the Rust migration gives it runtimes; DeepSeek gives it cheap tokens; Anthropic's projected first profitable quarter shows who collects when it spends. If the next billion users of your product aren't people, what were you building for the last ten years?

Five agreements across today's sources

  1. Agents are becoming the primary consumers of software. Agents already drive nearly half of documentation traffic at Mintlify (Ramdial); auth.md exists so they can register for services; the MCP RC redesigns the protocol for fleets, not sessions. Three independent layers, one customer.
  2. The infrastructure for non-human users is being standardized right now. The MCP RC locked May 21; auth.md shipped May 25 with Cloudflare, Firecrawl, Resend, and Monday.com on board. Four days apart, both make machine-readable text at a well-known location the front door to a service.
  3. Token economics are bending toward agent-scale consumption. DeepSeek made its 75% V4-Pro cut permanent (~2% of GPT-5.5's price); Anthropic's compute cost fell from 71 to a projected 56 cents per revenue dollar. Opposite strategies, same wager: agent demand grows without limit.
  4. The stack is stratifying by audience. Ramdial's 0.5 layer (auth, vector search, payments, inference) is in structural growth; the agent-first note documents the same stratification inside engineering — Python for the human scripting layer, Rust for the runtimes agents hammer.
  5. Chat is becoming the human's only seat. In one ten-day window, Higgsfield put every frontier model behind one chat, Google Stitch made design a streaming conversation, and OpenAI put ChatGPT inside PowerPoint. Humans state intent; agents do the clicking.

§2 · The thesisThe 0.5 layer and the audience that doesn't read landing pages

Neevash Ramdial's The AI Bifurcation of Tech is the day's organizing essay. His model splits the stack three ways: raw infrastructure at the bottom, applications at the top, and between them a 0.5 layer of primitives software gets assembled from — auth, vector databases, payments, inference, documentation hosting. His claim: AI hasn't created new product requirements; it is enforcing old ones, because the new consumer of your product is an agent that reads docs literally, tolerates no flaky endpoints, and judges you on whether calls return 200 in under 300 milliseconds. The receipts: Turbopuffer at $100M annual revenue in 19 months on under $1M raised; Modal's $355M Series C at $4.65B; Mintlify reporting agents now drive nearly half of all documentation traffic.

The line that matters isn't AI-native versus legacy. It's whether your product can be consumed by something that doesn't read landing pages. — Neevash Ramdial, The AI Bifurcation of Tech

The agent-first development note supplies what Ramdial leaves implicit: the second audience is restructuring engineering itself. The fastest-growing agent repos of Q1 2026 are written in Rust, and teams tell the same story — conceive the system in Python, re-engineer it in Rust once it must be concurrent, always-on, and cheap, because the GIL was never built for ten thousand simultaneous non-human callers. The synthesis neither source states alone: language choice has become an audience choice. Python is where humans sketch; systems languages are where agents live — the stratification databases went through, replayed at machine speed. And the economics making agent-assembled software real sit in Ramdial's I/O datapoint: an Antigravity 2.0 demo built a functioning OS in 12 hours with 93 sub-agents and 2.6 billion tokens — for under $1,000. That bill is only payable in a world where §4's price war is happening.

§3 · The plumbingMCP goes stateless, auth.md opens the front door

The MCP 2026-07-28 release candidate, locked last Thursday, is the most consequential spec revision since the protocol launched. The headline: MCP is now stateless at the protocol layer. The initialize handshake and sessions are gone; protocol metadata travels in _meta on every request; a server that used to need sticky sessions and a shared session store can sit behind a plain round-robin load balancer, route on an Mcp-Method header, and let clients cache tools/list for as long as ttlMs permits. State doesn't vanish — it moves into explicit handles the model passes back as tool arguments, visible instead of hidden in transport metadata. Around the core: MCP Apps (server-rendered UIs in sandboxed iframes), a redesigned Tasks extension, six SEPs hardening authorization toward real OAuth/OIDC practice, and formal deprecation of roots, sampling, and logging. Final spec lands July 28; Tier 1 SDKs ship inside the ten-week window.

Four days after the RC locked, WorkOS shipped auth.md — an open protocol that lets agents register accounts on behalf of users, discoverable through a markdown file at your domain. The file declares which flows a service supports: agent-verified, where the agent's identity provider vouches for the user with no human in the loop, or user-claimed, where the agent triggers an OTP and the human confirms. It composes boring existing standards — OAuth Protected Resource Metadata, ID-JAG assertions — and Cloudflare, Firecrawl, Resend, and Monday.com shipped support on day one. The synthesis no single source states: both releases make the identical move. Coordination that lived in session state or human ritual — handshakes, signup forms, sticky sessions — gets flattened into stateless, cacheable, machine-readable text at a well-known location. The agent web is being built the way the human web was: plain files, HTTP semantics, caching headers. That humility is why it will probably work.

CounterMind the hype gap: the framing circulating this week — MCP as the standard that lets agents "communicate and share memory seamlessly" — is not what the RC says. The text is strictly client–server plumbing; there is no agent-to-agent channel and no shared memory in it. Statelessness pushes memory out of the protocol, into handles the application must manage. The spec got more boring and more deployable at once, and the boring reading is the correct one.

§4 · EconomicsOne cost curve, two opposite bets

Two money stories anchor the day, and they are mirror images. DeepSeek made its 75% discount on V4-Pro permanent — pricing due to expire May 31 is now the list price: $0.435 per million input tokens, $0.87 output, roughly 2% of GPT-5.5's price for frontier-tier capability. V4-Pro cut long-context inference to about a quarter of the compute and a tenth of the memory of its predecessor, and DeepSeek passed the whole gain through to the API price — market share over margin, and open pressure on every Western lab's rate card.

Anthropic made the opposite choice with the same physics. Contrary Research's breakdown centers on one ratio: compute spend per dollar of revenue — 71 cents in Q1, a projected 56 in Q2 — which, with revenue more than doubling to a projected $10.9B for the quarter (Claude Code alone above $2.5B), would make Q2 the first profitable quarter in the company's history, conveniently ahead of an IPO expected this fall. Falling inference costs became margin instead of price cuts. The synthesis: the price war and the profitability story are the same wager read from opposite sides. Both only pay if agent-scale demand keeps compounding — DeepSeek is buying the second audience's traffic, Anthropic is monetizing it — and both confirm §2: when the token reprices toward commodity, durable revenue migrates to whoever owns the workflow (Claude Code) or the primitive (the 0.5 layer), not the raw intelligence.

§5 · The surfaceChat becomes the human's only seat

Three product launches in a ten-day window, three different giants, one identical shape. Higgsfield's Supercomputer (May 14, the subject of today's video source) puts every frontier model — Claude Opus 4.7, GPT-5.5 Pro, Gemini 3.1 Pro — plus its stable of media models behind a single chat agent with 40+ tools and three layers of memory: describe the reel or the week of content, and the agent plans, routes, renders, and learns from the run. Google Stitch (announced at I/O last week, free) replaced turn-based design with a real-time streaming agent that renders UI onto the canvas as you type or speak, with multiplayer editing — while Figma charges $15 a seat for the workflow Stitch is dissolving. And OpenAI put ChatGPT inside PowerPoint (May 21): generate and edit decks conversationally without leaving the app, pulling context from Gmail, Outlook, and SharePoint, down to the free tier.

The cross-source point: the same inversion at three altitudes. The human no longer operates the application; the human states intent into a chat, and an agent operates the application — picks the model, places the component, builds the slide. Launches that look like the app layer fighting back are the app layer surrendering its interior: PowerPoint survives as a rendering target, design tools as canvases, creative suites as model menus. Combine with §2 and the bifurcation sharpens into a rule no single source states: an application now survives as the chat surface above the agent or the primitive below it — the middle, where humans used to click through workflows, evaporates.

CounterThe honest tension in today's set: Ramdial says the app layer is compressing, yet the week's loudest launches are application-layer products from OpenAI and Google. The reconciliation is uncomfortable for everyone smaller: distribution giants can convert their apps into agent surfaces and keep the seat; SaaS products that are neither the chat box nor the API underneath get squeezed from both ends. Compression isn't the app layer dying — it's the app layer consolidating into whoever already owns the user.

§6 · The stateFrom referee to shareholder

The day's outlier source — a Simon Last post circulating via TLDR's founders letter — points at the political layer of the same windfall. The backdrop is concrete: last week Washington announced $2B in grants across nine quantum computing companies with a novel condition — the federal government takes minority equity stakes in the recipients. IBM gets $1B for a domestic quantum-chip foundry; GlobalFoundries $375M for a 1% stake; D-Wave's $100M is entirely equity-based; publicly traded recipients jumped 15–30%. Alongside it, the idea getting oxygen in founder circles this week: if AI profits are about to become real — see §4 — proposals for a "national dividend" on those profits move from fringe pamphlet to plausible policy.

Put it next to Anthropic's projected first profitable quarter and the shape is hard to miss: the same quarter the first frontier lab is on track to cross into operating profit, the state starts taking equity in strategic compute. That is a regime change in posture — government as shareholder of the windfall rather than referee of the risk — and it lands precisely because the windfall finally exists. The synthesis worth logging: the agent economy's three claimants surfaced in one week's reading — labs (margin), infrastructure owners (the 0.5 layer), and now the state (equity and dividends). The fight over who captures agent-generated surplus has formally started, before most application companies have noticed their customer changed species.

§7 · The long viewWhat breaks when half your traffic isn't human

Take Mintlify's number seriously — agents already near half of documentation traffic — and run it forward across today's stack. Per-seat pricing breaks: the seat was a proxy for a human clicker, and the clicker is leaving (§5). Marketing breaks: the new audience doesn't read landing pages and can't be retargeted — Ramdial's point about rigor over brand polish is really a point about where sales budgets go to die. Analytics break, because "users" becomes a category error. Security breaks the other way: auth.md's agent-verified flow — no human at registration — is exactly what makes fraud teams sweat, and the OAuth hardening in the MCP RC reads like the protocol authors know it. Even the dev-tools hierarchy breaks: when the hot path is ten thousand concurrent agent calls, the GIL is a business problem, and language stratification (§2) is the stack reorganizing around its heaviest user.

The falsifiable version, for the ledger. If the second-audience thesis is right: the MCP final spec lands July 28 with Tier-1 SDK support inside the window; auth.md files appear on major SaaS domains by autumn; an analytics vendor ships agent-traffic segmentation as a headline feature this year; and post-IPO lab earnings calls report agent/API consumption growing faster than chat subscriptions. If agent traffic instead plateaus at a novelty fraction of the web by year-end, today's issue overweighted a vendor narrative — auth.md is a WorkOS product launch wearing a protocol's clothes, and Contrary's arithmetic is projection, not a filed result. Write the checkpoints down now; grade them later.

§8 · Practical takeawaysIf you only do six things this week

  1. Run the three-year test on everything you own. For each product or internal tool: if an agent were handed the task it serves, would it call you or assemble the outcome from 0.5-layer pieces? Sort your portfolio into Figure 2's panels and be honest about the left column.
  2. Read the MCP release candidate before July 28. The stateless core changes your deployment story for the better — plain load balancers, cacheable tool lists, explicit handles. Budget the migration inside the ten-week window, not after the final spec lands on you.
  3. Publish (or at least draft) an auth.md. Even if you wait on the agent-verified flow, writing down how a non-human registers for your service exposes every place your signup assumes eyeballs. The protocol is a markdown file; the audit is the real product.
  4. Reprice your model menu against DeepSeek's new floor. Frontier capability at ~2% of GPT-5.5's price changes which tasks justify premium tokens. Re-run the routing math; what was uneconomical for agents in April may be free-tier cheap now.
  5. Check your docs traffic for agents. Mintlify's near-half number is a leading indicator you can measure on your own properties today. If agents are a third of your docs reads, your docs are an API surface — write them for the literal reader.
  6. Profile your hot path before the second audience finds it. The Python-to-Rust stories all start with an agent workload melting a prototype. If you expect agent callers, load-test at fleet concurrency now and decide deliberately what stays in the scripting layer.

§9 · GlossaryTerms used above, briefly

Second audience
Ramdial's framing for software agents as a user base parallel to humans — one that never sleeps, reads documentation literally, ignores brand, and judges services purely on interface quality and latency.
The 0.5 layer
The stratum between raw infrastructure and applications: auth, vector search, payments, inference, docs hosting — the primitives agents assemble outcomes from. Growing because every agent-built product draws on it.
Stateless MCP
The 2026-07-28 release candidate's core change: no handshake, no sessions. Protocol metadata travels in _meta on every request, so any server instance can answer any call behind a plain load balancer.
Explicit handle
The MCP RC's replacement for protocol-managed state: an identifier returned by a tool call that the model passes back in later calls. State becomes visible to the agent, not hidden in transport metadata.
auth.md
An open WorkOS-published protocol: a markdown file at a service's domain telling agents how to register accounts on a user's behalf, via an agent-verified (no human) or user-claimed (OTP) flow. Built on OAuth standards.
Language stratification
A maturing stack splitting by layer: Python as the human scripting and prototyping layer, Rust and other systems languages as the runtime layer where agent concurrency and cost dominate.
Inference margin
Revenue minus compute cost per dollar served. Anthropic's compute fell from 71¢ to a projected 56¢ per revenue dollar; DeepSeek converted the same efficiency into a permanent 75% price cut instead.
National dividend
The policy idea — newly plausible alongside government equity stakes in quantum firms — that the state should hold shares in the AI windfall and distribute returns to citizens: taxing the boom by ownership, not by rate.
